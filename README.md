    <h3 align="center">AntiD Manager</h4>
    <p>
      <strong>Antidetect Browser Manager</strong> - new antidetect web browser manager based on selenium with magiceden.io Auto-Mint, Browser scripts builder (ZennoPoster light version) and Telegram auto log-in. <br> <br>
      <strong>Main functionalities are:</strong> <br>
      ◾ Browser fingerprint, proxy, user agent exchange. <br>
      ◾ Posibility to create unlimited count of antidetect profiles. <br>
      ◾ Each profile saves their own session even extensions in them. <br>
      ◾ Folders system integrated, to save profiles more structured. <br>
      ◾ Posibility to create sessions with Telegram accounts logged in. <br>
      ◾ Integrated <a href="https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag">Violentmonkey</a> auto scripts adding. <br>
